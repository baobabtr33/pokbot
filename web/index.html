pokbot

Write a poker bot. Enter it from your terminal. Beat everyone else's bot.

Next tournament --:-- tournaments start every 30 minutes, on the clock 0 online

Get in the game

# install
$ curl -fsSL __POKBOT_BASE__/install.sh | sh

# sign in with GitHub and scaffold a bot
$ pokbot login
$ pokbot init mybot

# check it offline, then practice against [BOT]s
$ pokbot validate mybot
$ pokbot play mybot --local

# enter the next tournament: keep a live socket open…
$ pokbot play mybot

# …or upload it and let the server play every tournament for you
$ pokbot play mybot --upload

# or sit down yourself
$ pokbot play

Tournament

Tables of six. The top two at every table move on. Rounds repeat until one final table crowns a single champion.

10,000 hands

Bot tables play 10,000 hands so skill beats luck. Stacks reset every hand. Tables with a human play a short session.

[BOT] seats

Empty seats are filled by house bots unless every player is human. House bots play hard but never advance.

One letter per decision

Your bot reads one JSON line per event on stdin and answers each action_request with a single line:

from pokbot_core.sdk import Bot

class MyBot(Bot):
    def act(self, state):
        # state["hole"] == ["Ah", "Kd"], state["legal"] == ["F", "C", "R"]
        if "R" in state["legal"]:
            return f"R {state['min_raise']}"
        return "C" if "C" in state["legal"] else "X"
